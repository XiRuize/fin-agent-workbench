# ADR 0002：四栏固定布局

- 状态：Superseded by [ADR 0004](0004-workbench-shell-over-four-panes.md)
- 日期：2026-11-09

## 背景

金融研究是「对话 + 审核 + 资料 + 交付物」并行的任务。单栏聊天会把证据、假设、文件、报告都埋进消息流，无法签字、对比、回退。

候选：

1. 单栏聊天 + 抽屉。
2. Tab 切换（对话/文件/报告）。
3. 四栏固定布局，可折叠。

## 决策

选 **3**：左一对话、左二假设核准、左三文件树、左四预览/修改。默认宽度 24% / 20% / 18% / 38%，允许折叠；窄屏降级为 Tab。

## 理由

- 研究时需要同时看到「结论、证据、原文、成稿」。
- 审批是独立队列，不应埋在聊天里。
- 文件树与预览需要稳定位置，避免频繁切换上下文。

## 后果

**正面**

- 审批、证据、成稿同屏，减少来回跳转。
- 每栏可以独立演进、独立测试。

**负面**

- 1440px 以下会拥挤，需要折叠/窄屏策略。
- 四栏的滚动、焦点、快捷键需要统一设计。

## 交互约定

- 左二无待审时收成窄条，不占满宽。
- 左四四个 Tab：预览 / 源码 / 对比 / 评论。
- 评论锚到 `block_id`，不是像素坐标。
- 编辑分块级与源码级；默认块级。

## 复核条件

- 用户调研显示 80% 时间只在一栏。
- 四栏导致 1366px 笔记本不可用。
