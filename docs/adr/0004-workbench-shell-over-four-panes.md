# ADR 0004：用工作台壳替代固定四栏

- 状态：Accepted
- 日期：2026-11-09
- 取代：[ADR 0002](0002-four-pane-workbench.md)

## 背景

ADR 0002 选的是「对话 / 核准 / 文件树 / 预览」四栏固定布局。实际评审发现三个问题：

1. 1440px 下四栏已经拥挤，K 线、成交量、指标副图没有可用宽度。
2. 用户不是同时看四栏；多数时间是「一个主任务 + 偶尔看对话/资料」。
3. 固定四栏把「页面切换」压成「面板常驻」，移动端和窄屏不可用。

参考 [dsh-media-desk](https://github.com/woniuniuniu/dsh-media-desk) 的「左轨 + 单画布 + 可折叠 Dock」和 [Nuwax](https://github.com/nuwax-ai/nuwax) 的模块化面板，重新设计壳层。

## 决策

采用 **左轨 + 单主画布 + 可折叠 Dock**：

- 左轨 56px：研究 / 行情 / 文件 / 报告 / 核准 / 看板 / 设置。
- 主画布：一次一个模式；模式内部用 2–3 个可折叠面板。
- 对话默认左 Dock 320px，检查器默认右 Dock 280px；可折叠、换边、浮层。
- 行情是独立模式，K 线拿下整屏宽度；研究模式底部只留迷你 K 线。
- Focus 模式隐藏全部 Dock；布局按 `workspace + mode` 持久化。
- 深链 `#/mode/:entity` 恢复现场。

## 理由

- K 线需要横向宽度，不能塞进 280px 的栏。
- 模式切换比四栏常驻更贴近「研究 → 行情 → 报告 → 核准」的任务流。
- 折叠 Dock 保留「随时问一句」的能力，又不永久占用画布。
- 与 DSH / media desk 的极简风格一致，便于复用 token 与交互。

## 后果

**正面**

- 主画布获得完整宽度；行情、报告、审批都能独占。
- 窄屏可降级为单列 + 抽屉。
- 面板可独立复用（文件树同时用于研究/文件模式）。

**负面**

- 需要 layout store、面板注册、模式路由，前端复杂度高于固定四栏。
- 模式切换必须保留状态，否则用户会丢失滚动/选中。
- 需要 B1 先验证 DSH 插件能否承载这种壳。

## 复核条件

- 1280px 下研究模式无法同时容纳文件树 + 画布 + 对话。
- 模式切换超过 100ms 或状态丢失无法修复。
- DSH 插件无法承载，fork 成本超过 4 周。
